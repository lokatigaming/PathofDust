PayPal Sandbox Test Checkout — $1.00

Open this file locally (double-click it) and log in with a Sandbox buyer test account — find its email/password under Sandbox → Accounts in the PayPal Developer Dashboard. Completing this fires a genuine, properly-signed Sandbox webhook at the relay Worker, same as a real payment would — but free and repeatable as many times as needed.

Before this works, the Worker needs its Sandbox secrets set (see cloudflare-paypal-relay/worker.js's header comment): PAYPAL_API_BASE = https://api-m.sandbox.paypal.com, plus Sandbox values for PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET, and PAYPAL_WEBHOOK_ID (from a Sandbox-mode webhook subscription pointed at the same Worker URL).
